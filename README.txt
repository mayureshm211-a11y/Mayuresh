SARASCHAND JOYERA MULTI-PAGE WEBSITE + DASHBOARD

FILES
- index.html: first/home page
- collections.html: second page with gold/silver products, filters, search and cart
- about.html: About page
- contact.html: contact information and demo enquiry form
- admin.html: admin login and dashboard
- style.css: shared responsive black-and-gold design
- common.js, collections.js, contact.js, admin.js: JavaScript functionality

RUN
1. Extract the ZIP file.
2. Keep all files in the same folder.
3. Open index.html in a browser.
4. Use the navigation menu to move between pages.
5. Admin login: username admin, password joyera123.

DEMO LIMITATIONS
- Product list and demo orders use localStorage in this browser. They are not shared across devices.
- Login credentials are in front-end JavaScript and are NOT secure.
- Checkout creates a demo order only; no real payment is processed.
- Product names, prices and stock are sample data. Confirm actual details with the shop.
- The contact enquiry form only shows the entered message on screen; it does not send it.
- For a real public store, add server-side authentication, backend, database, validation, HTTPS, and a trusted payment provider.
- Confirm the full street address and weekly opening days before publishing.
